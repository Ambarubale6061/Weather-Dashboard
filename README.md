# Weather Dashboard

This is a ready-to-run React project (skeleton) for a Weather Analytics Dashboard.
It includes:

- React + Redux Toolkit
- Recharts visualizations
- Sample dataset with 30+ countries (simulated historical data)
- Professional CSS styling
- Search, Favorites, Unit toggle, Dashboard, Detail view
- Caching stub and refresh every 60s

To run locally:

1. Extract the zip.
2. `npm install`
3. `npm start`

Note: The sample dataset is used for charts offline. The app includes code to integrate with OpenWeatherMap API if you add `REACT_APP_WEATHER_API_KEY` in a .env file.

## Added features

- Firebase Google Sign-In and Firestore-based favorites persistence (configure via .env.firebase.example)
- Polished SVG icons in `src/icons`
- Animated transitions using Framer Motion
- Map view (react-leaflet) and Wind direction polar chart (Recharts RadarChart)

Run `npm install` to install new dependencies before `npm start`.
